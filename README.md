# AWS IAM & EC2 Web Hosting Project

## Project Overview
This beginner-level AWS project demonstrates how to launch an Amazon EC2 Linux instance, configure security group rules, install an Apache web server, and host a basic HTML website.

## AWS Services Used
- Amazon EC2
- AWS IAM
- EC2 Security Groups
- Amazon Linux 2023
- Apache HTTP Server

## Implementation Steps
1. Launched an Amazon EC2 Linux instance.
2. Configured SSH and HTTP inbound rules.
3. Connected to the instance using EC2 Instance Connect.
4. Installed and started Apache HTTP Server.
5. Created an HTML webpage and hosted it on EC2.
6. Tested website access through the public IPv4 address.

## Project Files
- `index.html` — Website source code.
- `README.md` — Project documentation.

## Learning Outcomes
- EC2 instance setup and management.
- Basic IAM and AWS security concepts.
- Security group configuration.
- Linux commands and Apache web hosting.

## Cost and Security
Resources should be monitored for charges and terminated when no longer needed. SSH access should be restricted to trusted IP addresses.
